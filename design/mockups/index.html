What’s genuinely good

Worth stating, so the list above reads in proportion.

BuilderDirty tracking fingerprints node positions and rolls back the snapshot on save error — a detail most implementations miss. The empty-canvas decision is deliberate, with a comment naming the bug it prevents.
WorkflowsThe delete dialog enumerates exactly what cascades and what survives. The import flow warns, by name, which skills will act without human approval.
ModelsDirect CLI distinguishes not-installed / not-authed / ready with the correct remedy for each — the pattern the rest of the page should copy. The log viewer is real operator UI.
ConnectorsThe only page with a correct error state that names the likely cause. OAuth guidance is per-client, not generic.
InspectorInline help beats most commercial tools — including a security warning that appears only when Direct CLI is selected. ModelPicker is exemplary and is the in-repo template for fixing the skill picker.
BackendPath-traversal guards, require_admin on every filesystem-touching route, and output truncation before insert so a runaway agent can’t blow up a row.
