What changed, and which gap each one closes.
  1. Readiness strip + disabled Run. Today executionReady is only “is a repo selected”, so a graph with empty objectives, orphan nodes or no edges starts a real run. Every blocking issue is named and clickable.
  2. Invalid nodes marked on the canvas. Red ring, corner badge, reason inline — so “what’s left to configure?” is answerable without opening all 15 nodes.
  3. Header says unsaved changes. isDirty is already computed and currently feeds only the nav guards, never the UI.
  4. Undo / Redo / Duplicate — the three missing direct-manipulation primitives.
  5. “Apply to selected” rather than to everything, covering skills and memory scope, not just the three runtime fields.
  6. Palette gains search and click-to-add. It is drag-only today, so every node type is unreachable by keyboard.
  7. Skill picker gains search, grouping and preview — mirroring ModelPicker, which already solves this exact problem 175 lines away.
  8. Prompt fields resize and expand. Capped at 240px in a 300px rail today, with resize-none disabling the browser’s own affordance.
  9. Runtime folded into “advanced” so set-once fields stop competing with the objective.
  10. Minimap coloured by node type — one line; the accent palette already exists in every node component.

Not shown, because they are behavioural rather than visual: the eight P0 data-loss fixes (template-load confirmation, draft baseline, awaiting the save on “Save and leave”, node-id collisions). Those ship first.
