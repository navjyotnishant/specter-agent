What changed.
  1. Provenance is visible. Three groups — built-in, imported (named by repo), hand-written. source_repo is already fetched and never read; today the only split is “in the database or not”.
  2. The frontend’s 11 hardcoded skills are deleted. They share zero names with the 11 the backend seeds, so nothing dedupes and users see two unrelated libraries — one of which is inert and cannot be attached to a node until saved.
  3. Compatible agent roles becomes a real editable field. Today metadataFromDraft returns [] unconditionally, so every save silently wipes it — and no UI displays the field, so the loss is invisible.
  4. “Restore built-ins”. Seeds are insert-if-missing, so a deleted built-in never returns — and a template referencing it breaks silently.
  5. Delete confirms; editing a built-in forks a copy instead of overwriting.
  6. Search stays, grouping is added. A single flat list is already long at 18 and unusable at 100.

Also not visual: a background refetch can re-resolve the selection and reset an in-progress edit, discarding unsaved changes with no warning — there is no dirty-state tracking on this page.
