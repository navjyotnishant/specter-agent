  1. Filter + status chips + sort. None exist today — the list renders in whatever order the API returned, and descriptions are clipped so even Cmd-F misses them.
  2. Sparkline of the last 5 runs replaces a single status word. “3 of the last 5 failed” is the question operators actually ask; today it needs five clicks to answer.
